# Installation walkthrough

- [Watch the 30-second MP4](install-ezeapply.mp4) — 1920 × 1440, 30 fps.
- [GIF preview](install-ezeapply.gif) — 960 × 720, 12 fps.
- [Poster](install-poster.png) and [captions](install-transcript.vtt).

These are original illustrated macOS/Chrome scenes, not a recording of a real
account or installation. The workflow is: download the ZIP, open Downloads,
extract the folder, open `chrome://extensions`, enable Developer mode, choose
Load unpacked, select the folder containing `manifest.json`, then open EZEapply.

Keep the extracted folder after installation. Chrome loads the extension from
that location. Updating means replacing its files in place and clicking Reload
in Chrome's extension manager; removing the extension can delete its local data.

Editable source and rendering instructions: [media-src](../../media-src/README.md).
